# DevOps CI/CD Project

## Overview
This project demonstrates a complete CI/CD pipeline using AWS EC2, Nginx, and GitHub Actions.

## Features
- Hosted website on AWS EC2
- Nginx web server
- Git version control
- Automated deployment using GitHub Actions

## Workflow
1. Code is pushed to GitHub
2. GitHub Actions triggers deployment
3. EC2 server pulls latest code
4. Website updates automatically

## Technologies Used
- AWS EC2
- Linux (Ubuntu)
- Nginx
- Git & GitHub
- GitHub Actions

## Result
A fully automated deployment pipeline with live website updates.
